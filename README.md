# 📚 다문화 친구와 통하는 삼국 언어 단어장

초등학교 4학년 다문화 언어 교육을 위한 **중국어 · 베트남어 · 필리핀어(타갈로그어)** 6개 영역 100개 핵심 어휘 원어민 발음 학습 웹 애플리케이션 및 파워포인트(한쇼) 연동 단어장입니다.

---

## 🌟 주요 특징

1. **실제 원어민 오디오 (MP3 300개 완비)**:
   - 🇨🇳 **중국어 (100단어)**: 현지 표준 중국어 원어민 음성
   - 🇻🇳 **베트남어 (100단어)**: 정확한 성조의 베트남 현지 원어민 음성
   - 🇵🇭 **필리핀어 (100단어)**: 자연스러운 타갈로그어 원어민 음성
   - 인터넷 연결 없이도 로컬에서 100% 즉시 재생

2. **3가지 학습 모드 제공 (`index.html`)**:
   - 📑 **표 모드**: PPT 슬라이드 표와 동일한 구성으로 3개국 언어를 한눈에 비교
   - 🗂 **플래시 카드 모드**: 큼직한 카드로 집중 학습
   - 🎯 **발음 퀴즈 모드**: 원어민 발음을 듣고 알맞은 한국어 단어를 맞추는 인터랙티브 퀴즈

3. **스마트 오디오 제어**:
   - 0.8x (천천히) / 1.0x (보통) / 1.2x (빠르게) 발음 속도 조절
   - `▶ 연속 듣기`: 중국어 ➔ 베트남어 ➔ 필리핀어 순으로 자동 순차 재생

4. **파워포인트 / 한쇼(HanShow) 슬라이드쇼 1:1 연동**:
   - PPT 슬라이드 쇼(`F5`)에서 표 안의 단어를 누르면 브라우저 발음창이 뜨며 원어민 발음 자동 재생

---

## 📂 파일 구조

```text
├── audio/                      # 3개국 100단어 실제 원어민 고음질 MP3 파일 (총 300개)
├── play/                       # PPT 슬라이드쇼 클릭 시 열리는 단어별 전용 재생 페이지 (300개)
├── index.html                  # 다국어 단어 학습 인터랙티브 웹 애플리케이션
├── player.html                 # 공용 팝업 오디오 플레이어
├── words.js / words.json       # 100개 단어 전체 구조화 데이터 (한국어, 중국어/병음, 베트남어, 필리핀어, 발음)
├── 단어학습_실행.bat            # 윈도우 더블 클릭 바로가기 런처
├── 초등4학년_다문화언어교육_단어장_100-v2.xlsx # 원본 100단어 엑셀 데이터
└── 다문화 친구와 통하는 삼국 언어 단어장 (발음완전연결).pptx # 발음 재생 하이퍼링크가 탑재된 PPT
```

---

## 🚀 실행 방법

### 방법 1. 웹 단어장 실행 (추천)
- `단어학습_실행.bat` 또는 `index.html`을 더블 클릭하여 실행합니다.

### 방법 2. PPT 슬라이드쇼 연동
- `다문화 친구와 통하는 삼국 언어 단어장 (발음완전연결).pptx` 파일을 엽니다.
- `F5`를 눌러 슬라이드쇼를 시작하고, 표의 단어를 클릭하면 발음이 재생됩니다.
